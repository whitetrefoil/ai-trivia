不完全是同一种东西！😄

你看到的字母上方那些小符号，比如 **é、è、ê、ë、ā、ǎ、ñ、å**，虽然长得有点像，但在不同语言中，它们的名称、作用，甚至是否属于字母本身，都可能完全不同。

它们有一个统称，叫作 **附加符号（Diacritic）**，也叫**变音符号、区别符号**。不过，“变音符号”这个中文名称有点容易误导，因为它们并不一定用来改变发音。

## 一、先认识这些符号

| 字母 | 符号名称 | 英文名称 |
| --- | --- | --- |
| á | 锐音符 | Acute accent |
| à | 重音符 | Grave accent |
| â | 扬抑符 | Circumflex |
| ä | 分音符／变音符 | Diaeresis / Umlaut |
| ã | 波浪号 | Tilde |
| ā | 长音符 | Macron |
| ă | 短音符 | Breve |
| ǎ | 抑扬符 | Caron |
| å | 上圆圈 | Ring above |
| ȧ | 上加点 | Dot above |
| ő | 双锐音符 | Double acute |
| ȁ | 双重音符 | Double grave |

注意：这些名称描述的是**符号的形状或传统名称**，并不意味着它们在所有语言中都有相同功能。

## 二、同一个符号，在不同语言里可以完全不是一回事

最有意思的就是这一点。

### 1. é：上面一撇

| 语言 | 作用 | 举例 |
| --- | --- | --- |
| 法语 | 区别元音音质 | été（夏天） |
| 西班牙语 | 标记重读音节 | café（咖啡） |
| 越南语 | 标记声调（锐声） | má（妈妈） |
| 冰岛语 | 表示特定元音，属于独立字母 | ég（我） |
| 汉语拼音 | 标记第二声 | má（麻） |

也就是说，同一个 `´`，在法语中主要关乎元音怎么发，在西班牙语中关乎哪个音节重读，在越南语和汉语拼音中则可以表示声调。

### 2. ä：上面两个点

**ä**

**德语：Umlaut（变音）**

表示与 a 不同的元音，例如 Mann → Männer（男人 → 男人们）。

**ï**

**法语：Tréma（分音符）**

提醒读者相邻元音应分别发音，例如 naïve 中的 a 和 ï。

**ä**

**芬兰语：独立字母**

ä 是芬兰语字母表中的独立字母，并不是书写时随意给 a 加两个点。

德语的 Umlaut 和法语的 Tréma，虽然今天看起来都是两个点，但历史来源和语言功能并不相同。

## 三、这些符号究竟能起哪些作用？

大致可以分为五类：

1. **改变元音或辅音的读音**：德语 ä、葡萄牙语 ã、捷克语 č。
2. **标记重音位置**：西班牙语 á、é、í 等。
3. **标记声调**：汉语拼音 mā、má、mǎ、mà；越南语也有类似系统。
4. **标记元音长短**：拉脱维亚语 ā 表示长元音；日语罗马字中的 Tōkyō 也用 ō 表示长音。
5. **区分单词或保留历史拼写信息**：法语 où（哪里）和 ou（或者）；法语 forêt 中的 ê 也与历史拼写有关。

而且，附加符号不一定在字母上面。

例如法语的 **ç**（下加软音符，Cedilla）、波兰语的 **ą**（下加尾符，Ogonek）、越南语的 **ạ**（下加点），也都属于 Diacritics。

## 四、加了符号以后，还是原来那个字母吗？

这也是一个非常有趣的问题：**由具体语言决定。**

例如：

- 英语中，é 通常被看作带附加符号的 e，主要出现在外来词中。
- 德语中，ä、ö、ü 是具有特殊地位的字母，排序规则还会随使用场景变化。
- 瑞典语中，å、ä、ö 是三个独立字母，排在字母表末尾，顺序就是 å、ä、ö。
- 西班牙语中，ñ 是独立字母，排在 n 后面。

所以不能简单地说，所有的 é 都是 e 的变体，也不能说所有带符号的字母都是独立字母。

## 五、还有一个有趣的现象：符号会叠罗汉

**ắ　ằ　ẵ　ẳ　ặ**

*越南语中的五种实际字母组合*

越南语特别擅长这件事。

比如 **ắ** 可以拆成：

- `a`：基础字母
- `◌̆`：短音符，构成 ă，表示特定元音
- `◌́`：锐音符，表示声调

这里不是两个符号重复表达同一件事，而是**一个决定元音是什么，另一个决定声调是什么**。

顺便一提，现代计算机的 Unicode 也支持这种组合：一个看起来完整的字母，有时在内部实际上由基础字符和一个或多个组合附加符号构成。

---

还有个值得注意的细节：你可能会发现 **汉语拼音的第三声 ǎ，和捷克语的 č 上面的符号是同一种形状（Caron）**，但捷克语用它来区分辅音，而汉语拼音用它表示声调。

这恰好说明了整个体系最核心的特点：

**符号的形状可以跨语言共享，但符号的意义是各个语言自己规定的。**
