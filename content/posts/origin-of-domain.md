**Domain 最原始的意思是「领地、领土、支配范围」**，带有相当浓厚的封建时代色彩。今天计算机领域的「域」「域名」，其实很好地继承了这个词的原始含义。

## 1. 词源：领主的领地

Domain 的词源可以追溯到拉丁语：

- **domus**：家、住宅
- **dominus**：主人、领主
- **dominium**：所有权、统治权、领地

经过古法语进入英语，最终演变为 domain。

因此，domain 最初强调的并不是一块土地本身，而是**某个人拥有所有权、控制权或统治权的范围**。

例如：

> The king's domain.
>
> 国王的领地。

与它同源的英语单词还有：

| 单词 | 含义 |
|---|---|
| Dominate | 支配、统治 |
| Dominion | 统治权、领土 |
| Domestic | 家庭的、国内的 |
| Domain | 领地、支配范围 |
| Demesne | 封建领主的直属领地 |

根据 Etymonline 的词源记录，现代拼写的 domain 在英语中大约于1600年前后出现，而同源的 demesne 则可以追溯至1300年前后。([domain](https://www.etymonline.com/word/domain)、[demesne](https://www.etymonline.com/word/demesne))

## 2. 计算机出现之前的用法

随着时间推移，domain 从物理上的领地逐渐扩展到了抽象意义上的领域。

1727年已有「管辖范围、活动范围」的用法，1764年已有「知识领域」的用法。([Etymonline](https://www.etymonline.com/word/domain))

在计算机诞生之前，它就已经被广泛用于各种场景：

| 英文 | 中文 |
|---|---|
| Royal domain | 王室领地 |
| Public domain | 公共领域、公有领域 |
| Eminent domain | 国家强制征收权 |
| Domain of knowledge | 知识领域 |
| Domain of science | 科学领域 |
| Domain of a function | 函数的定义域 |
| Magnetic domain | 磁畴 |
| Time domain | 时域 |
| Frequency domain | 频域 |

这些用法虽然看似五花八门，但都有一个共同的核心概念：

**具有一定边界、归属关系或适用规则的范围。**

## 3. 为什么计算机领域选择了 domain？

互联网的域名系统（DNS）于1983年正式提出，其分层管理结构恰好与 domain 原本的含义十分契合。

甚至可以拿封建领地的结构来理解：

| 封建领地（类比） | DNS |
|---|---|
| 整个世界 | 根域 `.` |
| 王国 | 顶级域 `.com` |
| 贵族领地 | `example.com` |
| 下属封地 | `blog.example.com` |
| 领地内的具体建筑 | 具体主机 |
| 领地的管理权 | DNS 管理权限 |
| 分封领地 | DNS Delegation（域委派） |

这当然只是结构上的类比，并不是说 DNS 的设计者真的参考了封建制度。

而计算机领域其他使用 domain 的地方，也基本延续了这个含义：

- **Windows Domain（Windows 域）**：统一身份认证和管理的范围。
- **Security Domain（安全域）**：适用特定安全规则的范围。
- **Broadcast Domain（广播域）**：广播数据包能够传播的范围。
- **Domain-Driven Design（领域驱动设计）**：围绕特定业务领域进行软件设计。
- **Domain-specific Language（领域特定语言）**：适用于特定问题领域的语言。

## 4. 中文的「域」其实翻译得非常妙

中文的「域」本身也有疆域、地域、境域的含义，同样经历了从具体空间到抽象范围的语义扩展。

因此，domain 在不同场合翻译成「领地」「领域」「定义域」「域名」，都能保留其原本的语义逻辑。

某种意义上，你每次注册域名，都是在互联网的命名空间里取得一块有期限的数字领地；你甚至可以把子域委派给别人管理。

只不过现代的数字领主不需要向国王宣誓效忠，每年记得续费就行了。🤣
